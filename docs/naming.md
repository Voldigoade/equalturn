# Project name

**Selected name: Equalturn** (`equalturn` as the repository and binary name).

The name points to equal opportunity in a competition without claiming that local software can guarantee a level playing field. It remains relevant if the project expands from AI access controls to broader integrity state, reporting, and session coordination. It is pronounceable, short enough for a binary, and avoids cyber-security branding clichés.

## Candidate screen

Candidates were compared for fit beyond AI chat blocking, pronunciation, binary/repository usability, and obvious software/security collisions. A name was removed when search found an established or directly adjacent product, a material exact-name project cluster, or confusing proximity to a well-known product. The selected name is the best balance of distinctiveness and breadth in this preliminary screen, not an assertion of legal availability.

## Final pre-release screen

A final exact-name screen for **Equalturn** was performed on **19 October 2026**:

- GitHub repository search was run broadly and with `equalturn in:name`; both returned no repositories. The public [GitHub repository search](https://github.com/search?q=Equalturn&type=repositories) is a reproducible view, though search indexing and private repositories limit what absence means.
- The exact package pages reported no package on [crates.io](https://crates.io/crates/equalturn), [npm](https://www.npmjs.com/package/equalturn), and [PyPI](https://pypi.org/project/equalturn/).
- The official [EUIPO eSearch](https://euipo.europa.eu/eSearch/#basic/1+1+1+1/100+100+100+100/Equalturn) UI exact query showed zero results in the trade mark, design, owner, and representative tabs.
- The official [USPTO Trademark Search](https://tmsearch.uspto.gov/) Wordmark query `Equalturn` showed “No results found,” with zero live and dead results. There is no stable public permalink for this query.
- General quoted web searches for `"Equalturn" app OR software OR company`, `"Equalturn" cybersecurity OR security`, `"Equalturn" trademark OR brand`, and `"Equalturn" product` surfaced no identifiable software/security product. Results were noisy, including unrelated OCR text and a malformed autogenerated product description. Product Hunt- and SourceForge-scoped search-engine queries also surfaced no matching product; those are weak discovery signals, not exhaustive catalog searches.
- The [WIPO Global Brand Database](https://branddb.wipo.int/branddb/en/) could not be searched because it presented an anti-bot challenge. No conclusion is drawn from WIPO, and the challenge was not bypassed.

No material software, security, or product collision appeared in the accessible checks, so **Equalturn is locked as the project name for this implementation milestone**. This is a preliminary screen, not legal clearance or a guarantee of exclusive use. The exact-word searches do not resolve confusing similarity, goods/services overlap, common-law use, foreign or unindexed registrations, or ownership. No separate TMview review, comprehensive state/common-law search, or domain-availability check was performed. Recheck before public launch, package publication, or trademark filing.
