# Project name

**Selected name: Equalturn** (`equalturn` as the repository and binary name).

The name points to equal opportunity in a competition without claiming that local software can guarantee a level playing field. It remains relevant if the project expands from AI access controls to broader integrity state, reporting, and session coordination. It is pronounceable, short enough for a binary, and avoids cyber-security branding clichés.

## Candidate screen

Candidates were compared for fit beyond AI chat blocking, pronunciation, binary/repository usability, and obvious software/security collisions. A name was removed when search found an established or directly adjacent product, a material exact-name project cluster, or confusing proximity to a well-known product. The selected name is the best balance of distinctiveness and breadth in this preliminary screen, not an assertion of legal availability.

## Collision research performed

Checked exact GitHub repository search, general web search, indexed PyPI/npm/crates.io/pkg.go.dev searches, and the USPTO Wordmark search UI for Equalturn, Rulepair, and Equalterms on **19 October 2026**. USPTO returned “No results found” for all three; GitHub repository search returned no exact-name results. Package checks were search-engine-indexed rather than exhaustive registry API queries. Exact-name web searches surfaced no relevant software product for these finalists. This is a narrow U.S. federal database check only: EUIPO/TMview, WIPO, foreign registries, common-law use, and domain availability were not checked. Domain availability was not used to choose the name and no domain was purchased or reserved.

This is a preliminary naming screen, not legal clearance or a guarantee of exclusive use. Equalturn is preferred over Equalterms because the coined name is easier to distinguish and use as a repository/binary identity, while both preserve the fair-competition idea. Recheck before public launch, package publication, or trademark filing.
