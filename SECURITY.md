# Security policy

Equalturn is in the research / architecture phase. It has no released executable or enforcement service.

When a vulnerability reporting channel is enabled on the project host, use private vulnerability reporting rather than opening a public issue with an exploitable detail. Include the affected revision, impact, reproduction conditions, and any mitigation. Do not include real participant data, credentials, or session invitation codes.

Security reports will be acknowledged and triaged by maintainers. Until a private channel is available, do not publish sensitive exploit details in an issue; contact a maintainer through a private channel linked from the repository profile.

Reports, session logs, and signed events are not proof that AI use did or did not occur. A participant with administrator/root control can tamper with local software, and remote or second-device use is outside the endpoint's trust boundary. See the [threat model](docs/threat-model.md).
